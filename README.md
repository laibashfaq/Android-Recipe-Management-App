# 🍽️ Magic Meal — Android Application

A user-friendly Android application designed to help users explore, discover, and manage meals efficiently. This project was developed using Android Studio as part of academic learning.

---

## 🚀 Features

- 🔍 Search meals by name or category  
- 📋 View detailed meal information (ingredients, instructions)  
- ❤️ Save favorite meals  
- 🗂️ Browse meals by categories  
- 📱 Clean and user-friendly UI

## 🛠️ Installation

### 1. Clone the repository
```bash
git clone https://github.com/laibashfaq/Android-Recipe-Management-App
```
### 2. Open in Android Studio
- Open Android Studio
- Click on "Open Project"
- Select the project folder


### 3. Run the App
Connect an emulator or physical device
Click Run ▶️
